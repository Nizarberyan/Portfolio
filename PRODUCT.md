# Product

## Platform

web

## Users
Primary users: Tech recruiters, engineering managers, and startup founders evaluating candidates for Senior / Lead Mobile Engineer roles (Flutter and React Native / Expo).
Situation: Rapidly scanning portfolios to assess whether the engineer possesses high design craft, deep mobile engineering mastery, and the ability to ship production-grade mobile applications.

## Product Purpose
Deliver an unforgettable first impression that proves top-tier mobile product engineering. Instead of presenting a static list of links and text cards, the portfolio operates as a living mobile design simulator that shapeshifts its entire design language—typography, atmospheric lighting, color palettes, card geometry, and layout—to reflect whichever mobile project is selected.

## Positioning
An interactive shapeshifting mobile engineering showcase that completely transforms into the design system and atmosphere of each featured mobile product (Zephyr Mobile, RideMate, HealthSphere, Resaly Pro). It demonstrates versatility across Flutter and React Native by putting visual fidelity and architecture depth on center stage.

## Operating Context
Evaluated in desktop browsers, laptops, and mobile screens. Demands rapid loading, tactile micro-interactions, responsive adaptability across screen sizes, and friction-free access to GitHub repositories, live screenshots, and architecture highlights.

## Capabilities and Constraints
- Interactive mobile phone simulator running real app screenshots (such as the Resaly Pro Flutter screens) and app previews.
- Dynamic design system morphing: seamless runtime transitions across Google Fonts (`Outfit`, `Syne`, `Space Grotesk`, `JetBrains Mono`, `Chakra Petch`), custom backdrop canvas effects, accent glow borders, and app dock styling.
- Fast, statically exportable React + Vite + TypeScript + Tailwind CSS architecture.
- Zero latency theme switching without layout jarring or broken render trees.

## Product Principles
- **Show, Don't Tell**: Let visitors experience the mobile app's authentic atmosphere directly on the portfolio rather than reading static bullet points.
- **Architectural Credibility**: Highlight real-world mobile challenges solved (offline sync, audio pipelines, GPS tracking, high-concurrency booking, custom shaders) alongside UI finish.
- **Fluid Shapeshifting**: State transitions between apps must be butter-smooth, tactile, and immersive.
- **Frictionless Discovery**: Recruiters can immediately inspect the tech stack, metrics, code repositories, and credentials within 10 seconds.
